# maquetado# 🌐 Portafolio Responsive

## 📌 Descripción

Este proyecto consiste en la creación de una página web tipo portafolio personal utilizando HTML5 y CSS3.

El objetivo principal es aplicar conceptos de estructura semántica, diseño con CSS Grid y Responsive Design, permitiendo que la página se adapte correctamente a diferentes tamaños de pantalla.

## 🎯 Objetivo

Aplicar los conceptos de:

- HTML5 semántico.
- CSS3.
- CSS Grid.
- Diseño Responsive.
- Media Queries.
- Colores, tipografía, bordes, márgenes y espaciado.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Para crear la estructura y contenido de la página.
- **CSS3:** Para aplicar estilos y diseño visual.
- **CSS Grid:** Para organizar las tarjetas del contenido.
- **Media Queries:** Para adaptar la página a diferentes dispositivos.
- **GitHub:** Para almacenar y publicar el proyecto.
